# Personalized Content Dashboard

## Features
- Personalized News Feed
- Drag & Drop Reordering
- Dark Mode
- Favorites System
- Debounced Search
- Redux Toolkit State Management
- Responsive Design
- Playwright E2E Testing
- Jest Unit Testing

## Tech Stack
- Next.js
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Framer Motion
- DnD Kit
- Playwright
- Jest

## Setup

npm install
npm run dev

## Run Tests

npm test
npx playwright test
